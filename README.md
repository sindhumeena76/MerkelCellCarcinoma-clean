# 🩺 A Robust Deep Learning Framework Using CNN and MobileNetV2 for Multiclass Skin Cancer Classification

## 📌 Project Overview
Skin cancer is one of the most dangerous diseases affecting millions of people worldwide. Early detection and accurate classification can help improve treatment success rates and reduce mortality. This project proposes a robust deep learning framework using Convolutional Neural Networks (CNN) and MobileNetV2 for multiclass skin cancer classification.

The system classifies different types of skin cancer from dermoscopic images using deep learning techniques and transfer learning. MobileNetV2 improves classification accuracy while reducing computational complexity.

---

## 🎯 Objectives
- To develop an automated skin cancer classification system.
- To classify multiple types of skin cancer using deep learning.
- To improve prediction accuracy using CNN and MobileNetV2.
- To reduce overfitting and training time.
- To assist healthcare professionals in early diagnosis.

## 📂 Dataset
The dataset consists of dermoscopic skin lesion images collected from the ISIC dataset.

### Dataset Classes
- Melanoma
- Basal Cell Carcinoma
- Benign Keratosis
- Dermatofibroma
- Melanocytic Nevi
- Vascular Lesions
- Actinic Keratosis

## ⚙️ Methodology

### 1. Data Preprocessing
- Image resizing
- Noise removal
- Image normalization
- Label encoding

### 2. Data Augmentation
- Rotation
- Flipping
- Zooming
- Brightness adjustment

### 3. Model Development
- Custom CNN model
- Transfer Learning using MobileNetV2
- Fine-tuning pretrained layers

### 4. Model Training
- Optimizer: Adam
- Loss Function: Categorical Crossentropy
- Batch Size: 32
- Epochs: 25–50

### 5. Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
